# Test-mail-data-base
educational project to study structures in cpp.

data base is saved in txt file "pochta_data_base.txt" (needs to be added in the same repository as code!)

code contains functions:
1) add new element
2) print mail data base
3) find letter by the name of sender
4) find clients who did not receive letter in time
5) find all letters with higher price
6) sort data base in descending order
7) exit
